# i9 Car — Link da bio

Página responsiva para o link da bio do Instagram da i9 Car Multimarcas.

## Publicar com GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch **main** e a pasta **/(root)**.
4. Clique em **Save**. O GitHub exibirá o endereço público da página nesta mesma seção.

## Ajustes pendentes

- O botão **Nosso catálogo** está direcionando provisoriamente para o WhatsApp do Arison, solicitando o catálogo. Quando houver uma URL pública do catálogo, substitua o href desse botão em `index.html`.
- Os consultores estão com avatares de iniciais (A e K). As fotos de perfil podem ser adicionadas depois como arquivos em uma pasta `assets/`.
- Os telefones e mensagens de WhatsApp já estão configurados com a mensagem: “Olá, vim do Instagram e queria saber mais”.
